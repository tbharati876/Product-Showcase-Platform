# PROJECT REPORT
## ShowCase – Product Showcase Platform

**Project Title:** ShowCase – Product Showcase Platform  
**Project Type:** Front-End Web Development Project  
**Technologies:** HTML5, CSS3, JavaScript  
**Deployment Platform:** Vercel  
**Source Code:** https://github.com/tbharati876/Product-Showcase-Platform

**Live Website:** https://product-showcase-platform.vercel.app/

**YouTube Demonstration:** https://youtu.be/8iZcdq0II5M

---

## 1. Project Objective

The main objective of the ShowCase project is to develop an attractive, responsive and user-friendly product showcase platform that allows users to explore products, browse categories and interact with essential e-commerce functionalities.

The website provides a simple shopping experience through features such as product discovery, product details, wishlist management, product comparison, customer reviews, user authentication, shopping cart and order management.

The project focuses on creating an organized interface with easy navigation, interactive elements and a responsive layout that works across desktop, tablet and mobile devices.

## 2. Technologies Used

The project was developed using the following technologies:

- **HTML5:** Used to create the structure and content of the website, including navigation, product sections, forms and page layouts.
- **CSS3:** Used for website styling, responsive layouts, visual effects, spacing, typography and mobile-friendly design.
- **JavaScript:** Used to implement interactive features such as product search, category filtering, sorting, authentication flow, wishlist, comparison, reviews, cart, checkout and order management.
- **Local Storage and Session Storage:** Used to store demo application data and maintain browser-based user session information.
- **Font Awesome and Google Fonts:** Used to improve the visual appearance through icons and typography.
- **Git and GitHub:** Used for source code management and version control.
- **Vercel:** Used to deploy and host the website.

## 3. Key Features Implemented

The ShowCase platform includes the following features:

1. **Homepage:** An attractive landing page with a hero section, featured products and category previews.
2. **Product Catalog:** Displays products with images, descriptions, prices, ratings and availability.
3. **Product Search and Filtering:** Allows users to search products, filter by category and sort by price, rating and name.
4. **Product Details:** Displays detailed product information, images, features and specifications.
5. **Categories:** Organizes products into different categories for easier browsing.
6. **Wishlist:** Allows users to save and remove favourite products.
7. **Product Comparison:** Allows users to compare multiple products and their specifications.
8. **Reviews and Ratings:** Displays customer feedback and supports demo review submission.
9. **User Authentication:** Provides registration, login, logout and a demo user profile.
10. **Shopping Cart and Checkout:** Supports adding products, changing quantities, removing items and placing demo orders.
11. **Order Management:** Provides an interface to view order details and order status.
12. **Admin Dashboard:** Supports basic product management, including adding, editing and deleting products.
13. **Responsive Design:** Provides layouts suitable for desktop, tablet and mobile screens.

## 5. Challenges Faced and Solutions

During development, several challenges were encountered.

- **Product Image Display:** Ensuring product images were displayed correctly across product cards and detail views required proper image paths and fallback handling.
- **Dynamic Product Filtering:** Implementing search, category filtering and sorting required coordinating multiple filtering conditions.
- **State and Browser Storage:** Maintaining cart, wishlist, user session and order information required consistent use of Local Storage and Session Storage.
- **Navigation and Authentication:** Connecting registration, login, profile and order sections required coordinating JavaScript modules and page navigation.
- **Responsive Design:** Adapting product grids, navigation and content sections to smaller screens required CSS media queries and layout adjustments.
- **Deployment:** Configuring the repository and deploying the static website required learning GitHub integration and Vercel deployment.

These challenges helped improve my debugging, problem-solving and web development skills.
