# ShowCase – Product Showcase Platform

## Project Overview

ShowCase is a responsive product showcase and shopping platform that allows users to explore products across multiple categories, compare product features, manage wishlists, and place orders.

The platform also includes customer authentication, profile management, and an administrator dashboard for managing products, customers, and orders.

## Features

### Customer Features
- Customer registration and login
- Customer profile management
- Browse products across multiple categories
- Search products by name and brand
- Filter products by category
- Sort products by price, rating, and name
- View detailed product information and images
- Add and remove products from wishlist
- Compare multiple products
- View and submit customer reviews
- Add products to shopping cart
- Checkout and place orders
- View account information

### Admin Features
- Administrator authentication
- Admin dashboard
- View registered customer accounts
- View customer orders
- Manage products
- Add, edit, and delete products
- View store information

### Additional Features
- Responsive user interface
- Product images and descriptions
- Category-based product browsing
- Toast notifications
- Product detail modal
- Navigation between application sections
- Browser storage for demo user sessions and application data

## Technologies Used

## Data Storage

The project uses browser LocalStorage to store application data such as registered users, products, reviews, wishlist items, comparison data, and orders.

SessionStorage is used for the current login session.

Data is stored locally in the browser and is not shared between different users or devices.

## Deployment

The project can be deployed as a static website using GitHub Pages, Vercel, Netlify, or another static hosting provider.

## Note

This is a frontend demonstration project. Authentication and administrator access are implemented using browser-side JavaScript and storage. A production application would require secure server-side authentication, database storage, and payment integration.
